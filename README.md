# 机械革命无界 14 Pro 热键 OSD

适用于机械革命无界 14 Pro 的 Windows 热键提示工具，其他机型未经测试。需要 64 位 Windows 10（1703 及以上）或 Windows 11。

## 功能

还原官方原生 OSD 功能和UI 效果，并提供开机自启和大小写提示开关。

- 提示性能、均衡和静音模式。
- 提示键盘背光关闭及第 1 至第 3 档。
- 提示触控板开启和关闭。
- 提示 Caps Lock（大小写锁定）的开关状态。
- 托盘菜单可切换开机自动启动及大小写锁定卡片显示，大小写提示默认开启。
- 设置保存在当前用户的 Windows 注册表，重启程序后继续生效。

## 使用

便携版直接运行。MSI 和 EXE 安装向导可选择上级目录，实际安装到其中的 YaoOsd 子目录。安装时可勾选开机自动启动，之后也可通过托盘关闭。安装后可从 Windows 应用设置卸载。

托盘菜单的“显示大小写锁定提示”控制 Caps Lock 卡片。

开机自启写入当前用户注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，值名为 `YaoOsd`，值内容为带双引号的程序完整路径。关闭开机自启时会删除该值。
